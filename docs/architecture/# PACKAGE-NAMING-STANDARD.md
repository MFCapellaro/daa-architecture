# PACKAGE NAMING STANDARD

## Purpose

This document defines naming conventions for DAA packages, concepts and architectural elements.

Naming preserves semantic identity across the architecture.

## Concept Definition

Names are semantic identifiers.

A consistent naming system allows concepts to remain recognizable as the architecture evolves.

## Design Principles

DAA naming:

- prioritizes meaning over implementation,
- uses stable conceptual terms,
- avoids unnecessary abbreviations,
- preserves singular conceptual identity,
- maintains consistency across layers.

## Structural Pattern

### Packages

Package directories use lowercase names.

Examples:

```text
grammar/
kernel/
coherence/
knowledge/
evolution/
