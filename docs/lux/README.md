# LUX

## Purpose

LUX is the transmitance of condensed coherence.

LUX enables coherent meaning to traverse contexts while preserving identity.

LUX provides the conditions through which coherent systems become observable through their own coherence.

---

## Responsibility

LUX defines the conditions that allow condensed coherence to become transmissible.

It:

* preserves condensed coherence across contexts,
* enables coherent meaning to remain recognizable during transformation,
* connects attention with understanding,
* enables intention to emerge from coherent understanding,
* allows propagation to emerge through coherent transmission.

LUX defines the architectural property through which coherence becomes transmissible.
