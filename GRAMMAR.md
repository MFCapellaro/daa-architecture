# Grammar

Grammar is the single source of meaning in DAA.

Grammar establishes the shared conceptual language from which every architectural layer derives its meaning.

It exists before architecture takes shape because coherent systems begin with shared understanding. Meaning precedes expression, allowing the architecture to evolve while preserving conceptual continuity.

In DAA:

- Meaning precedes expression
- Identity is preserved through evolution
- Core consumes Grammar
- Domain consumes Core

Grammar remains stable so the architecture can evolve while preserving semantic continuity.
