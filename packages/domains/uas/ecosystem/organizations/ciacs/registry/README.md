# CIAC Registry

## Purpose

Contains factual records of individual Civil Aviation Instruction Centers
identified through the official ANAC registry.

Each record represents an organization as identified by the authoritative
source.

## Principle

A registry record preserves source evidence.

It does not evaluate the quality, reputation or commercial suitability of
the organization.

## Identity

Each CIAC record should preserve:

* official name;
* authorization identifier, when available;
* CIAC type;
* location;
* authorized instructional scope;
* source reference;
* retrieval date;
* current status.

## Historical Preservation

A change in authorization must not erase the previous state.

Historical states must remain traceable through source snapshots or
versioned records.

## Verification

The registry source is authoritative for the authorization status represented
at the time of retrieval.

Additional information discovered elsewhere must not overwrite source
evidence.

It may be represented separately as supplementary ecosystem information.
