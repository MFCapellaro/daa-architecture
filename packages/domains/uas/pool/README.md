# UAS Pool

## Collective Purchasing through Coherent Relationships

UAS Pool is a DAA domain application that enables collective purchasing by connecting organized demand with structured supply.

It transforms individual interests into collective opportunities while preserving simplicity, transparency, and relationship continuity.

---

# What UAS Pool Is

UAS Pool is a coordination system.

It connects:

```text
Participants

    ↓

Collective Formation

    ↓

Supplier Offers

    ↓

Completed Relationships
```

The system enables coherent connections between people interested in shared opportunities and suppliers capable of providing structured offers.

---

# What UAS Pool Is Not

UAS Pool is not:

A marketplace
An e-commerce platform
A payment processor
A product reseller

DAA does not replace commercial actors.

It provides the conditions for relationships to emerge and evolve.
