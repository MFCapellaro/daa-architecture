# AdaptiveAction

## Purpose

AdaptiveAction represents a coherent response
derived from a coherence assessment.

It expresses the intended adaptive direction
after evaluating system evolution.

## Role in Dynamics

AdaptiveAction connects understanding with
response.

CoherenceAssessment
↓
AdaptiveAction


## Principle

Action emerges from assessed coherence.

A system adapts by responding to its evaluated
state, not by reacting to isolated changes.

## Responsibility

AdaptiveAction provides:

- the coherence assessment that originated the action
- the description of the adaptive response

It does not:

- evaluate coherence
- modify relationships
- execute external operations

## Model

CoherenceAssessment

    ↓

AdaptiveAction

    ├── assessment
    └── description


## Architectural Meaning

AdaptiveAction represents purposeful change.

It preserves the distinction between:

Assessment
↓
Intent
↓
Execution

The action describes the adaptive direction while
leaving execution to higher-level mechanisms.
